# 🕹️ Mini Games Arcade

확률과 도파민 기반의 웹 미니게임 컬렉션입니다.

---

## 🎮 수록 게임 목록

### 1. ⚪ [플링코 1,000배 핀볼 도박 (Plinko 1,000X)](plinko/index.html)
- 12행 피라미드 핀 사이로 구슬이 튕기며 낙하하는 극한의 도파민 핀볼!
- 3단계 위험도 선택(낮음 16X / 보통 110X / 고위험 1,000X 잭팟).
- Canvas 60fps 실시간 물리 충돌 엔진, 핀 충돌음, 네온 트레일 연출.
- x5, x10 연타 투하 기능, 최근 당첨 배수 히스토리, 대박 당첨 컨페티 연출, 파산 구호금.

### 2. 🎰 [777 라스베이거스 슬롯머신 (Vegas Slots)](slot-machine/index.html)
- 클래식 3릴 슬롯머신, 중앙 페이라인 당첨 구조.
- 777 메가 잭팟 100배, 다이아 50배, BAR 25배 등 다양한 배당.
- ⭐ 스캐터 3개 당첨 시 5회 VIP 프리 스핀(모든 당첨 2배 배당) 가동.
- 릴 회전/정지/당첨/잭팟 Web Audio 효과음 및 컨페티 축하 연출, 파산 구호금.

### 2. 🚀 [로켓 크래시 (Rocket Crash)](crash/index.html)
- 1.00x부터 로켓처럼 치솟는 실시간 배수 탈출 게임!
- 폭발(Crash)하기 전에 캐시아웃(Cash Out)하여 베팅액 × 배수 획득.
- Web Audio API 사운드, 캔버스 애니메이션, 파산 구호금 지원.

### 3. 🔮 [구슬 홀짝 게임 (Odd-Even Game)](odd-even/index.html)
- 1~18개의 구슬 수를 보고 홀수/짝수를 맞히는 클래식 확률 게임.
- 연승 보너스 배당, 올인 베팅, 구슬 낙하 및 컨페티 시각 효과.

---

## 🚀 배포 및 실행 방법

1. **로컬 실행**: 루트 디렉터리의 `index.html`을 브라우저로 열면 게임 허브 포털이 실행됩니다.
2. **Vercel 자동 배포**: GitHub 저장소를 Vercel에 연동하면 push할 때마다 자동으로 최신 버전이 실시간 배포됩니다.
