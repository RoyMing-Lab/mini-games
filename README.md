# 🕹️ Mini Games Arcade

확률과 도파민 기반의 웹 미니게임 컬렉션입니다.

---

## 🎮 수록 게임 목록

### 1. 🎡 [유러피언 카지노 룰렛 (European Roulette)](roulette/index.html)
- 37개 번호(0, 1~36)와 회전 휠이 선사하는 정통 카지노 테이블의 꽃!
- 싱글 넘버(Straight Up, 36배/35:1), 더즌(3배), 컬럼(3배), 레드/블랙(2배), 홀/짝(2배), 로우/하이(2배) 등 다양한 베팅 포지션 지원.
- Canvas 기반 60fps 회전 룰렛 휠 & 반대 방향 볼 궤도 물리 시뮬레이션(트랙 주행, 프렛 충돌 바운스, 포켓 낙하 안착).
- Web Audio API 칩 클릭음, 볼 회전 마찰음, 황동 프렛 충돌음, 포켓 안착 찰칵음, 당첨 축하 팡파르 & 패배 사운드.
- 칩 셀렉터(100, 500, 1K, 5K, 10K), 다중 베팅 배치, 베팅 2배, 재베팅, 베팅 초기화, 최근 10회 당첨 번호 스트립, 보상형 광고 시청 칩 무료 충전(+5,000칩).

### 2. 🪙 [코인 토스 올인 스트릭 (Coin Flip Streak)](coin-flip/index.html)
- 앞뒤 맞히기 & 끝없는 2배 연승 질주! 도파민 폭발 올인 캐시아웃 게임.
- 1연승(2X)부터 10연승(1,024X)까지 기하급수적으로 치솟는 배당 사다리.
- 매 라운드 성공 시 언제든 **수익 확정(캐시아웃)** vs **다음 연승 올인 도전** 선택.
- CSS 3D 입체 물리 코인 플립 연출(공중 다축 회전 & 착지), 골드 킹 크라운(앞면) & 실버 스타 라이트닝(뒷면).
- Web Audio API 동전 튕김 핑 사운드, 착지 찰칵음, 연승 피치업 징글, 캐시아웃 짤랑음, 1,024배 대박 잭팟 사이렌 & 축하 컨페티.
- 칩 베팅(500, 1K, 5K, 10K, 1/2, 2X, ALL IN), 실시간 최고 연승 기록 및 최근 10회 히스토리 비드, 보상형 광고 시청 칩 무료 충전(+5,000칩).

### 3. 🃏 [카지노 21 블랙잭 (Casino 21 / Blackjack)](blackjack/index.html)
- 딜러와의 숨 막히는 두뇌 및 카드 확률 싸움! 클래식 카지노 정통 21 게임.
- 52장 x 4덱 슈(Shoe), Fisher-Yates 셔플링, 딜러 17 이상 스탠드 정통 룰.
- **히트(HIT)**, **스탠드(STAND)**, **더블다운(DOUBLE DOWN, 베팅 2배 & 1장 추가)** 등 완전한 플레이어 선택지.
- **내추럴 블랙잭(3:2 배당 = +1.5배)**, 일반 승리(1:1), 딜러 버스트, 무승부(PUSH) 원금 반환.
- Web Audio 카드 스냅 및 셔플링, 칩 베팅음, 블랙잭 팡파르, 승리/패배 효과음, 3D 카드 플립 연출.
- 칩 베팅(100, 500, 1K, 5K, 1/2, 2X, ALL IN), 실시간 승률/순손익 통계, 보상형 광고 시청 칩 무료 충전(+5,000칩).

### 4. 🏇 [픽셀 경마 베팅 배틀 (Pixel Derby)](horse-racing/index.html)
- 5두의 개성 넘치는 경주마가 펼치는 300m 직선주로 실시간 픽셀 레이스!
- 1번마(2.2X 안정형)부터 5번마(25.0X 기적의 복병 잭팟)까지 다채로운 배당과 컨디션 시스템.
- Canvas 60fps 부드러운 카메라 트래킹, 갤럽 모션 & 흙먼지 파티클, 막판 35% 구간 폭발적 스퍼트 & 역전 드라마.
- Web Audio API 출발 호른 팡파르, 질주하는 발굽 효과음, 당첨 징글 & 파산 사이렌, 축하 컨페티.
- 멀티 베팅(다중마 분산 베팅), 1/2, 2X, 균등 올인, 실시간 전적 및 승률/순손익 통계, 보상형 광고 시청 칩 무료 충전(+5,000칩).

### 5. 🎲 [마카오 주사위 식보 (Macau Sic Bo)](sic-bo/index.html)
- 주사위 3개를 쉐이커 돔에서 덜컹덜컹 흔들어 맞히는 마카오 카지노 정통 다이스 게임!
- 대/소(11~17 / 4~10), 홀/짝 1:1 배당, 애니 트리플 31배(30:1), 특정 트리플 180배(180:1) 대박 잭팟.
- 특정 더블(11배), 총합 4~17(최대 60배), 싱글 다이스(1~3배), 2주사위 조합(6배) 등 다중 베팅 지원.
- 아시안 마카오 스타일 주사위(1과 4에 붉은 점), 덜그럭 쉐이크 및 컵 슬램 Web Audio 효과음, 당첨 컨페티, 카지노 기록판 및 파산 구호금.

### 6. ⚪ [플링코 1,000배 핀볼 도박 (Plinko 1,000X)](plinko/index.html)
- 12행 피라미드 핀 사이로 구슬이 튕기며 낙하하는 극한의 도파민 핀볼!
- 3단계 위험도 선택(낮음 16X / 보통 110X / 고위험 1,000X 잭팟).
- Canvas 60fps 실시간 물리 충돌 엔진, 핀 충돌음, 네온 트레일 연출, 외곽 가이드 벽 및 마이너스 손실 구역.
- x5, x10 연타 투하 기능, 최근 당첨 배수 히스토리, 대박 당첨 컨페티 연출, 상단 및 파산 시 보상형 광고 시청 칩 무료 충전(+5,000칩).

### 7. 🎰 [777 라스베이거스 슬롯머신 (Vegas Slots)](slot-machine/index.html)
- 클래식 3릴 슬롯머신, 중앙 페이라인 당첨 구조.
- 777 메가 잭팟 100배, 다이아 50배, BAR 25배 등 다양한 배당.
- ⭐ 스캐터 3개 당첨 시 5회 VIP 프리 스핀(모든 당첨 2배 배당) 가동.
- 릴 회전/정지/당첨/잭팟 Web Audio 효과음 및 컨페티 축하 연출, 파산 구호금.

### 8. 🚀 [로켓 크래시 (Rocket Crash)](crash/index.html)
- 1.00x부터 로켓처럼 치솟는 실시간 배수 탈출 게임!
- 폭발(Crash)하기 전에 캐시아웃(Cash Out)하여 베팅액 × 배수 획득.
- Web Audio API 사운드, 캔버스 애니메이션, 파산 구호금 지원.

### 9. 🔮 [구슬 홀짝 게임 (Odd-Even Game)](odd-even/index.html)
- 1~18개의 구슬 수를 보고 홀수/짝수를 맞히는 클래식 확률 게임.
- 연승 보너스 배당, 올인 베팅, 구슬 낙하 및 컨페티 시각 효과.

## 🚀 배포 및 실행 방법

1. **로컬 실행**: 루트 디렉터리의 `index.html`을 브라우저로 열면 게임 허브 포털이 실행됩니다.
2. **Vercel 자동 배포**: GitHub 저장소를 Vercel에 연동하면 push할 때마다 자동으로 최신 버전이 실시간 배포됩니다.
